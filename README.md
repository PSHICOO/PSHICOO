# PSHICO

> Construindo ferramentas locais para transformar conhecimento em sistemas vivos.

Sou **PSHICO**, criador do **AETHER** — um ambiente desktop local-first para organizar notas, conexões e ideias em um universo de conhecimento interativo.

## Em construção

- **AETHER Desktop** — aplicativo local para explorar, relacionar e consultar conhecimento pessoal.
- **Experiências visuais interativas** — mapas de conhecimento, interfaces cósmicas e visualização de dados.
- **IA privada e local** — busca, síntese e conexões úteis sem depender de serviços externos por padrão.
